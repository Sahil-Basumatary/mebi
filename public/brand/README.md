# Hackollab brand marks

Official wordmark: serif lockup in a thin rectangular plaque (Blackstone-style). The word sits in the optical centre of the frame. Palette: black `#000000` and white `#FFFFFF` only.

## Files

| File | Use |
| --- | --- |
| `hackollab-wordmark-black.svg` | Primary logo on light backgrounds |
| `hackollab-wordmark-white.svg` | Logo on black / dark photography |
| `hackollab-mark-black.svg` | Square app / LinkedIn developer logo (vector) |
| `hackollab-mark-black.png` | Square raster upload (LinkedIn app logo, etc.) |

## Rules

- Do not round the frame.
- Do not add shadows, gradients, or colour accents.
- Prefer SVG. Use PNG only when a host requires raster.
- Minimum clear space: about half the letter height around the frame.
